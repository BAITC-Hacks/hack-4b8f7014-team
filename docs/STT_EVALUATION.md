# Небольшое сравнение распознавания, 23 сентября 2026

Источник: [Google FLEURS](https://huggingface.co/datasets/google/fleurs),
revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`, test, первые три аудиофайла
в архивах kk_kz и ru_ru. Всего шесть записей, без отбора по результатам.
Это чтение текста, а не совещания. Аудио и полные тексты остаются в data/eval,
не коммитятся. Подготовка скачивает публичные данные; распознавание локальное.

Whisper small и large-v3: CPU int8, язык задан ru/kk, VAD и word timestamps.
WER = сумма замен, пропусков и вставок / число слов эталона.
Нормализация: нижний регистр, ё→е, токены `\w+`; пунктуация не учитывается,
числа не преобразуются в слова. Это не процент неверно распознанных записей.

| Язык | Слов эталона | small | large-v3 |
|---|---:|---:|---:|
| Русский | 45 | 1/45 = 2,2% | 0/45 = 0% |
| Казахский | 57 | 41/57 = 71,9% | 15/57 = 26,3% |

Результат поддерживает переход на large-v3, но выборка слишком мала для
заявления общей точности. Смешанная речь, совещания на казахском, наложение
голосов, имена и качество извлечения поручений требуют отдельной разметки.
Нулевой WER на трёх русских фрагментах не означает безошибочность модели.

Воспроизведение из корня проекта после установки requirements-local.txt:

```powershell
python -m scripts.prepare_eval
python -m scripts.setup_models whisper --revision 536b0662742c02347bc0e980a01041f333bce120
python -m scripts.setup_models whisper-large-v3 --revision edaa852ec7e145841d8ffdb056a99866b5f0a478
python -m scripts.evaluate_stt --model models/whisper --output data/eval/small.json
python -m scripts.evaluate_stt --model models/whisper-large-v3 --output data/eval/large-cpu.json
```

Загрузчик сохраняет revision весов в provisioning.json; для строгого повторения
нужно использовать те же веса. prepare_eval закрепляет revision датасета.

Повтор на RTX 4060 Laptop 8 ГБ, CUDA int8_float16 дал те же суммарные
ошибки: RU 0/45, KZ 15/57. Это проверка совместимости, не замер скорости:
во время прогона параллельно выполнялась другая CPU-задача.

На пользовательской русской записи 206 секунд выполнен отдельный полный прогон
large-v3 GPU → Community-1 CPU → Qwen 7B. Предыдущий протокол сохранён.
Новый результат: 66 фрагментов, 29 без уверенного говорящего, 9 черновых
поручений (6 с подтверждённой цитатой, 3 требуют проверки источника), 4 строки
итогового отчёта. DOCX/PDF сформированы. Пунктуация стала лучше, ошибки имён
сохранились. Эталонного дословного транскрипта нет, WER этой записи не заявляется.
