# Живое совещание на Windows

Это локальный захват системного звука, а не бот Teams/Zoom. В звонок пользователь входит сам.

1. Установите дополнительные зависимости: `python -m pip install -r requirements-live.txt`.
2. Подготовьте локальную small-модель Whisper в `models/whisper` для чернового распознавания.
   Путь можно изменить через `MINUTES_LIVE_STT_MODEL_DIR`.
3. Запустите API, worker, Ollama и Streamlit обычным способом.
4. Откройте раздел «Живое совещание», нажмите «Показать устройства звука».
5. Выберите колонки/наушники, которые используются в Teams/Zoom, и нажмите «Начать живую запись».
6. Перейдите в звонок. Текст появляется блоками примерно по 20 секунд плюс время распознавания.
7. Нажмите «Остановить и сформировать итоговый протокол». После завершения черновой обработки
   вся запись передаётся обычному worker: основная STT → диаризация → поручения → PDF/DOCX.

Весь звук выбранного выхода записывается, в том числе уведомления других программ.
Собственный микрофон пока не включён: при использовании наушников собственные реплики
не попадут в запись. Требуется отдельное смешивание микрофона или виртуальный аудиомикшер.
Не включайте прослушивание микрофона через колонки: это может вызвать обратную связь.

Промежуточная STT использует CPU и small-модель; итоговая — профиль основной модели.
Примерно раз в минуту распознанной речи, если очередь не отстаёт, строится черновое саммари
и список поручений по последним 400 словам/сегментам. Это ещё не полный итоговый протокол.
Если компьютер не успевает, задержка растёт; финальная обработка использует всю сохранённую запись.
Диаризация в живом черновике не выполняется. Доступ к управлению записью — только с loopback.

Запись хранится в `data/uploads`, промежуточные фрагменты и состояние — в `data/live`.
Пределы: `MINUTES_MAX_AUDIO_SECONDS` и `MINUTES_MAX_UPLOAD_MB`, что наступит раньше.
Захват PCM занимает больше места, чем MP3: 200 MB при 48 kHz stereo — около 17 минут.
При закрытии backend запись прерывается; перед его перезапуском остановите запись.
Запись не возобновляется автоматически после перезапуска.

Проверено 23.09.2026 на Windows: захват системного выхода, 11,7 секунды тестовой речи,
13 распознанных слов/фрагментов, WAV сохранён и поставлен в очередь; тестовая очередь изолирована.
Проведены тесты остановки без звука, временных смещений и запрета чужого Origin.
Полный реальный звонок Teams/Zoom с несколькими участниками пока не проверен.

Источник WASAPI API: [PyAudioWPatch](https://github.com/s0d3s/PyAudioWPatch).
